# BVN THIRUKKURAL FACTORY — பூமி நலன்

## நோக்கம்
திருக்குறள் சார்ந்த கல்வி, மனிதநேயம், பொறுப்பான வாழ்க்கை முறை,
இயற்கைப் பாதுகாப்பு ஆகியவற்றை இணைத்து அறிவைப் பகிர்வது.

## தற்போதைய உள்ளடக்கம்
- `index.html` — தமிழ் project அறிமுகப் பக்கம்
- `styles.css` — மொபைல் மற்றும் கணினிக்கான வடிவமைப்பு
- `assets/` — பின்னர் சேர்க்கப்படும் சரிபார்க்கப்பட்ட assets

## உள்ளூர் ஆய்வு
`index.html`-ஐ உலாவியில் திறந்து, தமிழ் எழுத்துரு, இணைப்புகள்,
மொபைல் காட்சி ஆகியவற்றைச் சரிபார்க்கவும்.

## வெளியீட்டு விதி
GitHub Pages URL மற்றும் QR Code உருவாக்கப்பட்ட பின்,
அவற்றைத் திறந்து சரிபார்க்காமல் வெளியீடு வெற்றியடைந்ததாகக் கருத வேண்டாம்.
திருக்குறள் உரைகள் சேர்க்கப்படும்போது நம்பகமான மூலத்துடன் தனியாகச் சரிபார்க்கவும்.
